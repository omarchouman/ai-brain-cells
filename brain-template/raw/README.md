# raw

Full transcripts, long documents, and anything else too big to be a note.

Nothing here is retrieved by browsing. A note links to a file here when a
task needs the full depth behind it, and that link is the only way in —
which is why this folder can hold long things without bloating every
retrieval.

If you find yourself pasting a long document into a note, it belongs here
instead, with a short note pointing at it.
