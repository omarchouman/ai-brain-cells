# Your brain

This repo is yours. It ships empty on purpose — a brain seeded with
someone else's examples is one you have to clean out before it's useful.

`CLAUDE.md` is the contract every agent follows. Leave its structure
alone; the parts meant for you to write are listed below.

## Fill these in first, in this order

1. **`identity/core.md`** — who you are and what you're working toward.
   Ten honest lines beat a page of positioning.
2. **`identity/voice.md`** — the highest-leverage file here. It is an
   instruction manual for agents writing as you, and the thing that makes
   it work is *real sentences you actually wrote*. Rules describe a voice;
   examples transmit one. Two paragraphs of your own writing beat a page
   of adjectives about it.
3. **`taxonomy.md`** — your topics. Start with ten or so. Add more only
   when you have two notes that need the tag.
4. **`identity/beliefs.md`** — the positions that cut across everything.
5. **Your first project card**, then your first few notes.

## Then just use it

Write a note whenever you catch yourself having a position, learning
something, or telling a story with real numbers in it. The brain gets
useful faster than you'd expect — a dozen good notes already beat none.

Everything here is plain markdown in a normal git repo. Edit it in the
dashboard, in VS Code, or in `vim`. `git log` is your history. Nothing is
locked in.
