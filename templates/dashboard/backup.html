Setting it up

Create an empty private repository, then paste its URL above. SSH is the smoother path — an HTTPS remote needs a credential helper already configured, because this app will never prompt you for a password. Git is run with prompting disabled on purpose: a request that hangs waiting for input nobody can type looks exactly like the app freezing.

If a push fails with an authentication error, run git push once from a terminal inside {{ brain_path }}. Whatever it needs from you, it can ask for there.
