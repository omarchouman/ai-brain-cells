First run

Let's give you somewhere to think.

Your brain is a folder of plain markdown in its own git repository. Nothing about it is locked to this dashboard — you can edit it in VS Code, read it in a terminal, and delete this app without losing a word of it.

What gets created

  • identity/ — who you are, how you write, what you believe3 files
  • knowledge/ — takes, stories, lessons, factsempty
  • projects/ — one card per thing you're buildingempty
  • lenses/ — named retrieval scopesempty
  • CLAUDE.md — the contract every agent reads firstthe rules

It ships with zero notes, on purpose.

An empty brain that is genuinely yours beats a seeded one you have to clean out first. The identity files come as prompts, not placeholders to keep.
